# Deezer Music Search

เว็บค้นหาและเล่นตัวอย่างเพลง Deezer ที่ใช้ Express เป็น static server และ API proxy

## การติดตั้งและรัน

ต้องใช้ Node.js 18 หรือใหม่กว่า

```powershell
npm install
npm start
```

เปิดเว็บที่ `http://localhost:3000`

สำหรับโหมดพัฒนา:

```powershell
npm run dev
```

ตรวจสอบ server ได้ที่ `http://localhost:3000/api/health`
